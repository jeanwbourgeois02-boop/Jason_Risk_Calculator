# risk-monitor

FX risk monitor for the NMMF book at BNP: BNP report import, settlement-date cash ladder, live Bloomberg rates, P&L.

**Start here: [docs/HOW_IT_WORKS.md](docs/HOW_IT_WORKS.md)** — every tab, every calculation, every known limit, and the questions a PM will ask.

Run: double-click `launch.bat`. Install: `py -3 -m pip install -r requirements.txt`. Tests: `py -3 -m pytest tests/ -q`.
