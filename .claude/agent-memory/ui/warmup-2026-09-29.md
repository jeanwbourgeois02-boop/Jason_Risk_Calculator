User 2026-09-29 "the site is super slow": the first click after a start, upload or pull paid
one-time loads. `ui/warmup.py` (`start`, `after_change`, `status()`, `last_run`) runs the
tabs' OWN memo functions in order (priced_value_book, shared_spreads filled, shared_trade_book,
book.gather, header._build_figures + needed_marks, daily_series, pnl.base + pnl.period(DEFAULT),
shared_spreads raw + shared_curve, risk.gather + shared_trade_risk(wait=True),
risk_folds.book_positions + risk.stress_result). One worker thread, a pending flag for debounce,
re-runs (max 3) when the db signature changed mid-run.

**Why it must call the tabs' functions, not the engine:** the memo keys are
(kind, path from PRAGMA database_list, mtime, as_of, extra); only the same function on a
`connect_readonly` connection hits. Risk's first direct render was still 0.7-2 s until the
currency fold's `risk-book-positions` memo (a second curve_positions) and the stress memo were
added. A new memo kind on a tab = add it to `_screens`.

**Outside-inputs key (2026-09-29, coordinator):** the quarter-hour left `outside_inputs_key`;
it is each file's (mtime_ns, size), an empty `-wal` counting as None (a read-only open leaves one;
same rule as `commodity_history._cache_key`). Research writes land in the WAL or, after a
checkpoint, the main file; the as-of day is in every memo key. Never put wall-clock time back in
a memo key: it makes the Book and Risk go cold on a timer.

**Hooks (wired 2026-09-29):** `revision.warm_screens(get_db_path)` from create_app's
`if start_feed:` (as `warmup.start`), uploads._confirm after a good import, `_switch_book`, and
revision._poll when a new data revision is published (pulls, backfill). The Data tab's
Diagnostics fold opens with `warmup.status_line()` ("Warm-up: 3.2 s at 16:41, ok").

**Proof recipe:** scratchpad `warm/t.py cold|warm <db>`: fresh process, time book/pnl/risk
`.render` cold vs after `start()` + join of thread "screens-warmup". 2026-09-29: sample cold
6.8 / 7.0 / 1.9 s, warm 0.03 / 0.02 / 0.14 s; real (89 trades, no marks) cold 2.3 / 0.6 / 0.5,
warm 0.04 / 0.02 / 0.07. Warm-up itself 3-7 s (research history 0.6-1.4 s of it).
