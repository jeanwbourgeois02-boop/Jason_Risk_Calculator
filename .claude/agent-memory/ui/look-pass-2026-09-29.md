2026-09-29, user: the look of `C:\Users\jeanw\Ninemasts\Dashboards\risk-monitor` ("thats super slick"; READ-ONLY,
never edit or run it): its style.css and its Blotter `_filter_bar`. Layouts/functions of the six tabs were final;
the pass changed only the look. What is now true:

- Table heads are **navy with white bold text** everywhere (reverses the Phase E light-grey rule; the user's call).
  One kit for every hand-built `.book-table` (style.css block "the one table kit"): sticky-ish heads, zebra via
  `:where(tbody tr:nth-child(even))` (low weight on purpose, so row tints such as the Book's group rows win),
  hover `--hover`, totals (`tr.book-total`, tfoot) on `--total-bg` under a 2px navy rule, an 8px outline from
  the card or the table's own border (`.book-card:not(.card-pad) > .book-table` drops its own). dash_table heads
  navy through the `!important` rules; `market_data._HEAD` lost its inline grey.
- Tokens in `:root`: `--zebra --hover --total-bg --tint --neg-bg --pos-bg --top-bar-h` beside navy/gold/pos/neg/warn.
- Tiles (`.book-tiles/.book-tile .k .v`, Book, Exposure, P&L) are the reference's cards grid; section titles
  (`.book-section-title`) the reference's h4; `.book-download` is the ghost button; `.book-switch` a segmented
  control, chosen = navy + gold rule; the issues drawer's summary is the reference's `.details` (navy, gold hover).
- Book grid: heads `position: sticky; top: var(--top-bar-h)` (works only because `.book-grid-wrap` keeps
  `overflow: visible`); levels indented 18px per depth; group bold on `--tint`, position/instrument 600, leg
  plain, fill (`book-grid-trade`) muted 12px.
- Book filters: `book.filter_bar()` above the table (`.blotter-filter-bar book-filter-bar`): Search, Commodity,
  Type, Sector, Currency dropdowns ("All"), Clear filters (`CLEAR_FILTERS_ID`, now a `btn btn--ghost` in the bar,
  gone from the toolbar), then a "Figures" line of small comparison boxes. Same `book-f-<key>` ids and callbacks;
  `grid_head` is one row. `body()` renders the bar too.

**Why:** the user found the reference slick and its filters "super nice and convenient".
**How to apply:** new screens use these classes, never a new table style; a header-coloured element inside
a `th` needs a white-on-navy override (`.book-table th .about-mark`, `.marker`). Options sub-tab still uses
dash_table's native filter row (dormant tab; not converted).
