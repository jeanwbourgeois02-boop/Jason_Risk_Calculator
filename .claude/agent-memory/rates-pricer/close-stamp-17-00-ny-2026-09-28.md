`engine/rates/store.py::snapped_at` stamps 17:00 America/New_York of the row's own date (offset resolved), since 2026-09-28.

**Why:** user decision 2026-09-28, explicit yes under hard rule 7: "everything closes on its day at the time at which its specific exchange closes"; the app's one close stamp is Bloomberg's daily close for every mark and curve. The 15:00 New York close of 2026-09-21 was reverted the same week (it only ever applied 2026-09-21 to 2026-09-28).

**How to apply:** never reintroduce 15:00 in this lane; the stamp is shared by options-store, listed-options-pricer and bbg-curves (`vol_marketdata.py`), so any change to it is a Changed interface for them and needs the user's yes first. Related: [[curves-only-scope-2026-09-24]].
