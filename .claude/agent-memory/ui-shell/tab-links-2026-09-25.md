User approved 2026-09-25 ("can you apply these"): a tab's name on another screen is a link.
`ui/tabs/formatting.py::tab_link(label, tab_key, idx, title=None, className="")` renders an
`html.Button` (type=button, n_clicks=0, class `.tab-link`) with id
`{"type": "tab-link", "tab": key, "idx": idx}`; `ui/app.py::_follow_tab_link` (Input ALL/ALL
n_clicks -> `main-tabs.value`, prevent_initial_call) goes through the pure
`tab_from_link_click(ctx.triggered)`: n_clicks None/0 ignored, unknown key -> no_update.

**idx rule:** "<tab it sits on>-<spot>", plus the row key when repeated per row. Duplicate
pattern ids break the page in the browser, not in pytest.

**Why a button:** an `html.A(href="#")` changes the URL hash and jumps to the top; no
dcc.Location exists in the layout.

**Test gotchas (Dash 4.4.1):** `callback_map[key]` has no `prevent_initial_call`; read it from
`app._callback_list`. A pattern id appears in `callback_map[...]["inputs"]` as a JSON string
(`'{"idx":["ALL"],...}'`), so `tests/test_ui.py::test_every_static_callback_id_exists_in_layout`
flags it as missing unless ids starting with "{" are skipped. Invoke the raw callback with
`monkeypatch.setattr(dash, "ctx", SimpleNamespace(triggered=[...]))`. Heredocs turn `→`
into the literal arrow again (see [[display-helpers-2026-09-25]]).
